# 🚀 CareerTrack — Job Application Tracker

A modern, responsive, and user-friendly **Job Application Tracker** built with **HTML, CSS, and Vanilla JavaScript**.

CareerTrack helps job seekers organize their job applications, monitor application progress, manage interviews, and analyze their job search — all directly in the browser.

No backend server or external database is required. Application data is stored locally using **Browser LocalStorage**.

## 📌 Overview

Searching for a job often means applying to multiple companies and keeping track of different application stages.

**CareerTrack** provides a centralized dashboard where you can manage your entire job search from one place.

You can:

* Add new job applications
* Track application status
* Search and filter applications
* Organize applications using a Kanban board
* Monitor interviews
* View application statistics
* Export and import application data
* Manage your data directly in the browser

### 💾 Local Data Storage

CareerTrack uses **Browser LocalStorage** to store application data.

This means:

* No backend required
* No database server required
* No API required
* No account required for basic usage
* Works directly in the browser

> **Note:** LocalStorage data is stored only in the current browser/device. Clearing browser data or switching devices may remove the stored applications.

## 🚀 Getting Started

### Option 1 — Run Directly

Since CareerTrack is a static web application, you can run it without installing a backend or database.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

That's it! 🎉

---

### Option 2 — Clone Using Git

```bash
git clone https://github.com/YOUR-USERNAME/careertrack.git
```

Move into the project:

```bash
cd careertrack
```

Then open:

```text
index.html
```

in your browser.

---

## 🌐 Deployment with GitHub Pages

CareerTrack can be deployed using **GitHub Pages**.

### Steps

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
5. Click **Save**.
6. Wait for GitHub Pages to publish the website.

Your website will be available at:

```text
https://YOUR-USERNAME.github.io/careertrack/
```

## 🔐 Privacy

CareerTrack does not require a backend database for its core functionality.

Your application data is stored locally in your browser using LocalStorage.

No application data is automatically sent to a remote server by the core application.
